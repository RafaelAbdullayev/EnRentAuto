# Портфолио — Rafael Abdullayev

Одностраничный сайт-портфолио. Чистые HTML + CSS + JS, **без сборки и зависимостей**:
скачал → открыл → работает. Тёмная тема, неоновые акценты, glassmorphism,
анимации появления при скролле, магнитные кнопки, кастомный курсор, mobile-first.

```
portfolio/
├── index.html     # разметка + все стили (менять почти не нужно)
├── content.js     # ← ВЕСЬ КОНТЕНТ САЙТА. Обычно правите только этот файл
├── app.js         # рендер контента и вся интерактивность
├── editor.js      # визуальный редактор, грузится только при ?edit=1
└── assets/        # фото, og-image, скриншоты проектов
```

---

## 1. Как запустить локально

Двойной клик по `index.html` тоже сработает, но правильнее поднять локальный сервер
(иначе браузер может заблокировать загрузку `content.js` по протоколу `file://`):

```bash
cd portfolio
python3 -m http.server 5173      # или:  npx serve .
```

Откройте http://localhost:5173

## 2. Полный контроль: два способа редактирования

### Способ А — визуальный редактор (без кода)

Откройте сайт с параметром `?edit=1`:

```
http://localhost:5173/?edit=1
```

Справа снизу появится кнопка **«✎ Редактировать»**. В панели можно:

- менять любой текст, заголовок, ссылку и число;
- **добавлять, дублировать, удалять и двигать** проекты, услуги, этапы, каналы связи;
- нажать **«Применить»** — увидеть результат сразу (черновик хранится в вашем браузере);
- нажать **«Скачать content.js»** — получить готовый файл;
- **«Сброс»** — откатиться к тому, что лежит в `content.js`.

Последний шаг обязателен: скачанным файлом **замените `portfolio/content.js`** в проекте
и перезалейте сайт. Пока вы этого не сделали, правки видны только на вашем компьютере.

> Редактор подключается исключительно при `?edit=1` — обычные посетители его не грузят,
> и на скорость сайта он не влияет. Никакого пароля там нет, потому что и данных нет:
> всё хранится локально в браузере.

### Способ Б — прямо в `content.js` (быстрее, если не боитесь кода)

Откройте `content.js` в любом редакторе. Это один объект с понятными подписями:

```js
hero: {
  badge: 'Открыт для новых заказов',
  firstName: 'Rafael',
  lastName: 'Abdullayev',
  subtitle: 'Frontend & Backend Developer',
  description: 'Создаю быстрые, красивые и надёжные веб-продукты…',
}
```

Правило одно: текст всегда в кавычках, элементы списка разделены запятыми.

## 3. Частые задачи

| Что нужно | Где менять (`content.js`) |
|---|---|
| Имя, подзаголовок, описание в шапке | `hero` |
| Своё фото | положить `assets/avatar.jpg`, путь — в `about.avatar` |
| Био, цифры «N проектов / лет / клиентов» | `about.bio`, `about.stats` |
| Список технологий | `about.stack` |
| **Добавить проект** | скопировать любой объект в `projects.items` и поменять поля |
| Фильтры портфолио | `projects.filters` (id должен совпадать с `categories` проекта) |
| Услуги | `services.items` |
| Этапы работы | `process.steps` |
| Telegram / WhatsApp / GitHub | `contact.channels` и `footer.social` |
| Куда уходит форма | `contact.formMode` |
| Копирайт в футере | `footer.copy` |
| Цвета сайта | `theme` (или переменные в `:root` внутри `index.html`) |

### Превью проекта

Два варианта на выбор:

```js
preview: 'car',    // встроенный SVG-мокап: 'car' | 'saas' | 'bot' — грузится мгновенно
image: '',         // ИЛИ свой скриншот: 'assets/my-project.jpg' (имеет приоритет)
```

Скриншоты делайте в пропорции **16:9** (например 1280×720) и сжимайте в
[squoosh.app](https://squoosh.app) до 150–250 КБ — иначе просядет скорость загрузки.

### Форма обратной связи

Бэкенда у сайта нет, поэтому форма работает через мессенджеры (`contact.formMode`):

- `'whatsapp'` *(по умолчанию)* — открывает WhatsApp с уже подставленным текстом заявки;
- `'telegram'` — открывает чат, текст кладётся в буфер обмена;
- `'mailto'` — почтовый клиент (заполните `contact.email`);
- `'endpoint'` — отправляет JSON POST-запросом на ваш адрес. Задайте `contact.formEndpoint`,
  например форму [Formspree](https://formspree.io): `https://formspree.io/f/xxxxxxx`.
  Это единственный режим, где заявка приходит без участия мессенджера.

### SEO и превью-картинка

В `index.html`, в самом верху, замените `https://rafael.dev/` на ваш реальный домен
(теги `canonical`, `og:url`, `og:image`) и положите `assets/og-image.png` размером
**1200×630** — именно её увидят в Telegram, WhatsApp и соцсетях при отправке ссылки.

## 4. Деплой

### Vercel (рекомендую — свой домен и HTTPS бесплатно)

```bash
npm i -g vercel
cd portfolio
vercel --prod
```

На вопрос про сборку отвечайте пропуском: проект статический, build-команда не нужна.
Либо через сайт: [vercel.com/new](https://vercel.com/new) → импорт GitHub-репозитория →
**Root Directory: `portfolio`**, Framework Preset: **Other**.

### Netlify

Перетащите папку `portfolio` на [app.netlify.com/drop](https://app.netlify.com/drop) —
сайт поднимется за секунды. Для автодеплоя: подключите репозиторий, publish directory `portfolio`.

### GitHub Pages

```bash
git subtree push --prefix portfolio origin gh-pages
```

Затем Settings → Pages → Branch: `gh-pages`. Адрес будет
`https://<логин>.github.io/<репозиторий>/`.

### Свой домен

В настройках любого из хостингов добавьте домен и пропишите у регистратора запись
`A` / `CNAME`, которую он покажет. SSL выпускается автоматически.

## 5. Технические детали

- **Доступность**: семантические теги, `aria-label` у иконок и кнопок, фокус-кольца,
  корректные состояния формы (`aria-invalid`, `role="alert"`), контраст текста ≥ 4.5:1.
- **Производительность**: нет фреймворков и картинок в превью (SVG рисуется кодом),
  шрифты с `display=swap`, обработчики скролла через `requestAnimationFrame`,
  `IntersectionObserver` вместо слушателей скролла для анимаций.
- **`prefers-reduced-motion`**: при системной настройке «уменьшить движение» все
  анимации, параллакс и кастомный курсор отключаются автоматически.
- **Безопасность**: текст из `content.js` вставляется как текст, а не как HTML —
  случайные `<` и `>` не сломают страницу; внешние ссылки с `rel="noopener noreferrer"`.
- **Отказоустойчивость**: каждый блок JS обёрнут в `safe()` — ошибка в одном месте
  (например, опечатка в `content.js`) не роняет остальной сайт, а пишет причину в консоль.
